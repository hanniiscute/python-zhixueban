② 为什么你之前打不开

根因（一个文件，两段历史）。 这个项目早期用 SQLite 存数据，后来迁移到了 MySQL，但只迁了一半：
  • 文件还叫 app/db/sqlite_client.py（名字没改），但里面装的已经是 MySQL 客户端，建表脚本 migrations.py 也全是 MySQL 语法；
  • README 却还在写 "SQLite"，另一份文档写的是 ChromaDB —— 跟实际代码对不上，这就是你看不懂的最大原因之一；
  • 最致命的是：程序一启动就立刻连 MySQL 的 agents 库，而你电脑的 MySQL 里没有这个库，于是 Unknown database 'agents'，整个后端直接崩，前端自然白屏。

实测复现的报错：

pymysql.err.OperationalError: (1049, "Unknown database 'agents'")
  File "...\app\db\sqlite_client.py", line 90, in <module>
      db = MySQLClient()          ← 导入时就建连接池，库不存在 → 直接炸
好消息：除此之外项目本身相当完整。我把库建好后，注册、登录、 流式对话、画像提取、讲义/导图/出题/代码/路径生成，全部实测跑通，星火 API 密钥也是有效的。

⑤ 日常怎么启动（记这两段就够了）

第一次：需要装好 Python、Node.js、MySQL 8.0 并启动 MySQL 服务，root 密码写进 backend/.env。

最省事（推荐）：双击项目根目录的 一键启动.bat —— 它会自动弹出这两个窗口、检查 MySQL、12 秒后自动打开浏览器。想关闭就双击 停止服务.bat。

想手动开这两个窗口（学一下也有用）：

① 按键盘 Win + R，输入 cmd 回车，弹出一个黑色窗口 —— 这就是「窗口 1」，把下面两行粘进去（右键即粘贴）：

cd /d D:\2026-10-03-09-34-55\my-agent\backend
.venv\Scripts\python -m uvicorn main:app --host 127.0.0.1 --port 8000

② 再按一次 Win + R → 输入 cmd → 回车，开出「窗口 2」，粘这两行（2026-10-03 已装好官方 Node.js 24.21.0，直接用 npm run dev 即可）：

cd /d D:\2026-10-03-09-34-55\my-agent\frontend
npm run dev

小技巧：在文件夹里打开资源管理器，点一下上方地址栏，输入 cmd 回车，可以直接在当前目录开黑窗口，连 cd 都省了。

然后浏览器开 http://localhost:5173　·　接口文档 http://localhost:8000/docs

改了教材/习题/知识库之后，要重新生成索引（离线秒级）： cd backend && .venv\Scripts\python -m app.rag.indexer
改了后端 Python 代码，要在命令里加 --reload 才会自动重启，否则要手动重启。
